About

Hello, my name is Kyle Givler. I use I2P for software projects, experiments, alternate-network services, and assorted weird Internet nonsense.

This page is intentionally small and self-contained. It does not require external stylesheets, JavaScript, fonts, or other clearnet resources.

Services here are experimental and provided on a best-effort basis.

Why I2P?

Mostly because alternate networks are interesting.

I like building software and putting it somewhere other than the normal public web: I2P, Yggdrasil, DN42, Gopher, Gemini, and whatever other strange corner of the network seems fun to experiment with.

This is not intended to replace my clearnet presence. It is another entrance into some of the same projects, plus a place for things that make more sense on an alternate network.

Privacy and network boundaries

This landing page is deliberately self-contained. It does not intentionally load JavaScript, stylesheets, fonts, images, analytics, or other resources from the clearnet.

Linked services may have different requirements. An application available through I2P may still reference external resources or APIs unless its own page says otherwise.

About this site

This site is served by a small Go HTTP service running behind a Java I2P HTTP server tunnel.

The I2P router owns the destination and forwards requests to the local Go service. No nginx, external web framework, or third-party frontend assets are involved.
